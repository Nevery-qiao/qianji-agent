# 0.2.0：本机接入与真实定时验收

2026-10-20更新。本版提供后台MCP和配套Skill，不包含账单获取器或桌面操作机器人。

## 已实际验证

- 当前Mac上复用已登录的官方App，正常宿主加载0.2.0及10个工具入口。
- 原记账和管理Agent持续采用新MCP、原请求防重、完整挂起清单和当轮账户复核。
- 普通消费保存后核对原生账目字段、自然余额，再接续原台账、确认工具收尾并提交日报。
- 原管理和记账任务取得宿主真实定时唤醒证据。隔离假后端的专用异常跟进完成两次真实唤醒，并在受控故障结束后清理测试任务。
- 本地集成中修复原调用方台账衔接和取信预算。它们属于调用方职责，不是本MCP自带的邮箱获取或业务管理系统。

## 使用范围

目前适配官方macOS钱迹4.5.9/build1580。同机接入已验证；另一台Mac、不同账号、Windows/Linux或云端部署需独立验证。真实定时测试不证明客户端关闭、设备休眠或登录自然失效后仍能执行，调用方需提供宿主调度与恢复机制。

51个业务动作不等于所有组合都已验收，逐项状态见能力矩阵。分期、周期等未来执行和复杂关联保留各自边界；不把历史未知改成成功，不重置已耗尽的核验次数。

## 发布内容

源码、合成测试、MCP入口、Skill、能力矩阵和安装说明。不含真实账单、账号凭据、操作记录库、官方App二进制或开发机器私有证据。个人Agent的管理台账与专用适配不作为通用MCP依赖发布。

## 后续观察

长期日历运行、自然登录失效、跨机和第三方Agent兼容性需继续观察。最新调用方取信预算细节通过真实API离线检查，未来实际取信另行观察。本版不修改App或账号设置。
